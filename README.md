# Whose Robots.txt? Consent-Infrastructure Inequality Across the Languages of Web Corpora

This repository contains the current paper and its reproducible analysis.

The repository contains the archived robots.txt responses and census files, deterministic analysis, the figure generators used by the paper, and the manuscript source snapshot. Bibliography data, reviewer notes, LaTeX formatting files, build logs, and the compiled manuscript PDF are intentionally not included.

## Reproduce the analysis and figures

From this directory, run:

```sh
./reproduce.sh
```

The script:

1. regenerates `results/revision_results.json` from the archived files in `data/`;
2. regenerates the figures in `figures/`.

The analysis and figure build does not fetch live websites. The included `scripts/collect.py` documents the original collection pipeline, but rerunning collection is a separate network-dependent operation and can change as robots.txt files change. The manuscript source is retained for reference and is not part of the automated build.

## Requirements

- Python 3 with `matplotlib` installed

The analysis itself uses only the Python standard library; Matplotlib is needed for the figures.

## Important paths

- `scripts/analysis_revision.py` — current single-source analysis and result regeneration
- `scripts/analysis.py` — baseline release analysis
- `scripts/make_fig.py` — baseline release Figure 1 generator
- `scripts/make_fig_v2.py` — current Figure 1 generator used by the manuscript
- `scripts/make_fig_estimands.py` — current estimand-comparison Figure 2 generator
- `results/revision_results.json` — checked-in result snapshot, regenerated by the build
- `data/` — archived robots responses, censuses, and validation inputs
- `figures/` — generated figure outputs
- `paper/main.tex` — manuscript source snapshot

The repository does not include bibliography data, reviewer notes, LaTeX formatting files, build logs, or the compiled manuscript PDF.
