# Whose Robots.txt? Consent-Infrastructure Inequality Across the Languages of Web Corpora

This repository contains the current paper and its reproducible analysis.

The repository contains the archived robots.txt responses and census files, deterministic analysis, the figure generators used by the paper, and the ACL LaTeX manuscript source and formatting files. The bibliography data, reviewer response notes, and compiled manuscript PDF are intentionally not included.

## Reproduce the analysis and figures

From this directory, run:

```sh
./reproduce.sh
```

The script:

1. regenerates `revision_results.json` from the archived files in `data/`;
2. regenerates Figure 1 and the estimand-comparison Figure 2.

The analysis and figure build does not fetch live websites. The included `collect.py` documents the original collection pipeline, but rerunning collection is a separate network-dependent operation and can change as robots.txt files change. The manuscript source remains for reference, but its bibliography and compiled PDF are intentionally excluded.

## Requirements

- Python 3 with `matplotlib` installed
The analysis itself uses only the Python standard library; Matplotlib is needed for the figures. The ACL style and bibliography style are included locally, while the bibliography data and compiled manuscript are intentionally omitted.

## Important paths

- `analysis_revision.py` — current single-source analysis and result regeneration
- `analysis.py` — baseline release analysis
- `make_fig.py` — baseline release Figure 1 generator
- `make_fig_v2.py` — current Figure 1 generator used by the manuscript
- `make_fig_estimands.py` — current estimand-comparison Figure 2 generator
- `revision_results.json` — checked-in result snapshot, regenerated by the build
- `data/` — archived robots responses, censuses, and validation inputs
- `paper/main.tex` — current ACL manuscript source
- `paper/acl.sty` — ACL formatting macros used by `main.tex`
- `paper/acl_natbib.bst` — ACL bibliography style file
- `paper/acl_latex.tex` — upstream ACL example/template, not the manuscript itself

The repository does not include the bibliography data or compiled manuscript PDF.
