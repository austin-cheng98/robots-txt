# Whose Robots.txt? Consent-Infrastructure Inequality Across the Languages of Web Corpora

This repository contains the current paper and its reproducible analysis.

The repository contains the archived robots.txt responses and census files, deterministic analysis, the figure generators used by the paper, ACL LaTeX sources, bibliography, reviewer response notes, and the compiled nine-page paper.

## Reproduce the paper

From this directory, run:

```sh
./reproduce.sh
```

The script:

1. regenerates `revision_results.json` from the archived files in `data/`;
2. regenerates Figure 1 and the estimand-comparison Figure 2;
3. compiles `paper/main.tex` and writes `paper/main.pdf`.

The manuscript build does not fetch live websites. The included `collect.py` documents the original collection pipeline, but rerunning collection is a separate network-dependent operation and can change as robots.txt files change.

## Requirements

- Python 3 with `matplotlib` installed
- [Tectonic](https://tectonic-typesetting.github.io/) on `PATH`
- Poppler `pdfinfo` on `PATH` for the nine-page build check

The analysis itself uses only the Python standard library; Matplotlib is needed for the figures. The ACL style, bibliography style, bibliography, raw archived inputs, validation labels, and current derived results are included locally.

## Important paths

- `analysis_revision.py` — current single-source analysis and result regeneration
- `analysis.py` — baseline release analysis
- `make_fig.py` — baseline release Figure 1 generator
- `make_fig_v2.py` — current Figure 1 generator used by the manuscript
- `make_fig_estimands.py` — current estimand-comparison Figure 2 generator
- `revision_results.json` — checked-in result snapshot, regenerated by the build
- `data/` — archived robots responses, censuses, and validation inputs
- `paper/main.tex` — current ACL manuscript source
- `paper/main.pdf` — compiled manuscript

The expected final manuscript is nine pages when built with the included source and current Tectonic/ACL environment.
